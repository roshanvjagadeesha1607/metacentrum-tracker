# Installed MetaCentrum Tracker — Code Reference

This directory contains decompiled Java code recovered from
the developer's installed Android application.

It documents the later version, including password authentication.

These files are provided as a source-code reference, not a
complete or independently build-tested Android Studio project.

No APK, saved password, private key, or phone application data
is intentionally included.

## Security

The recovered application disables SSH host-key verification
and stores configuration using ordinary SharedPreferences.

This version has not undergone a complete security audit.
